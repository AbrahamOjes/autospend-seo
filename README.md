# Autospend.ai SEO Project

A programmatic SEO implementation for Autospend.ai, focusing on country-specific USDC transfer pages with multiple payment method support.

## Features

- Dynamic page generation for countries and regions
- Payment method integration in country pages
- SEO optimization with structured data
- Automatic sitemap generation
- Responsive design for all devices

## Getting Started

### Prerequisites

- Node.js 14.x or higher
- npm or yarn

### Installation

1. Clone the repository
```bash
git clone https://github.com/AbrahamOjes/autospend-seo.git
cd autospend-seo
```

2. Install dependencies
```bash
npm install
# or
yarn
```

3. Run the development server
```bash
npm run dev
# or
yarn dev
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser

## Project Structure

- `/components` - Reusable React components
- `/data` - Country and payment method data
- `/pages` - Next.js pages including dynamic routes
- `/public` - Static assets and generated sitemap
- `/scripts` - Utility scripts for sitemap generation
- `/styles` - Global CSS styles

## Deployment

The project is built with Next.js and can be deployed to Vercel or any other hosting platform that supports Next.js applications.

```bash
npm run build
npm run start
```
